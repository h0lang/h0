Native H0 Tape UTF-8. Header `N[name|-private|+extern]`, unnamed entry returns exit status. Args a,b,…, `'ab` shared byte views, `"cd` mutable; shared before mutable. LF or `;;` separates functions outside literals and comments. Call a std operation only with its module imported. Put `>+IDs` on line 1, or attach its Hangul import alias directly before the first header (e.g. `문0`). Preserve section order. SP ends instructions. Join prefix operands with only required TAB. TAB separates adjacent numbers, block counts, and named calls from identifier/digit operands. `:fn<TAB>ab` calls with a,b; numeric calls use source order, `:<`/`:>` neighbors, `::` self. Mutable call views disjoint.

Prefix u64 wrapping `+-*/%&^|<>EDLGSTAO` add/sub/mul/div/rem/and/xor/or/lt/gt/eq/ne/le/ge/shl/shr/lazy-and/or (two operands each, e.g. AAabc = (a&&b)&&c); `!` not, `N` negate, `~` bitnot, `\i` lazy cond/yes/no. `bx` binds or sets b; `+bx` adds x; `Yx` discards; tail x or `.x` returns. `?x` guards one statement, `?x<TAB>N[<TAB>M]` then N and optional else M. `@n<TAB>N` loop 0..<n with index in next free register; `Wx` while. `Wx(... )`, `@n(... )`, `\Dx(... )` take loop bodies with adjacent ( and standalone ). Nested statements count once. Block locals end at exit; assignments to outer registers persist. \=abxy evaluates x,y before updating existing u64 registers a,b. `'` breaks, backtick continues. `1sum b0 @a<TAB>1 +bc b` sums 0..<a.

`Za` len, `Bab` byte, `Xabc` store byte c at b, `Vabc` slice [b:c), `\vab` tail, `bMn` zero buffer. `Kab` splits mutable a for the next statement into two new registers, suspending a. `\B2/4/8` LE load(view,offset); `\Q2/4/8` store(mut,offset,value). `\b"…"` UTF-8 bytes, escapes `\0\n\r\t\"\\\xHH`. `1head'a ?<Za4.0 \B4a0` reads LE u32.
